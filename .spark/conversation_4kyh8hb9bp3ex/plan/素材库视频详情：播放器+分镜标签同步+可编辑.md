## 目标与成功标准

点击素材库中的视频素材卡片，不再弹出简单的详情 Dialog，而是打开一个「素材详情页/抽屉」，呈现类似分镜标签查看器的完整交互界面：
- 左侧视频播放器（可播放/暂停/进度条）
- 右侧当前分镜标签详情（画面描述/场景/物体/动作/镜头/卖点/旁白）
- 底部分镜时间轴（可点击跳转、当前分镜高亮）
- 标签可编辑、可添加自定义标签、可删除分镜
- 所有按钮操作后立即生效并持久化

成功标准：点击素材卡片 → 打开详情界面 → 视频可播放 → 播放时标签面板随时间同步切换 → 点击时间轴上的分镜可跳转 → 编辑标签后保存生效。

## 实现方案

### 1. 素材详情 Dialog（MaterialDetailDialog）
**布局**：全屏 Dialog（`size: "full"` 或 `max-w-6xl`），三栏结构与 VideoTagViewer 一致：
- 左上：视频播放器（复用 `VideoPlayerPanel`）
- 右上：当前分镜标签详情（复用 `TagInfoPanel`）+ 编辑按钮
- 底部：分镜时间轴（复用 `ShotTimeline`）+ 操作工具栏

**数据来源**：
- 如果素材在 `video-tags` 中有对应数据（通过 `videoFile` 或 `productName` 匹配），直接读取完整分镜数据
- 如果没有分镜数据（新上传未分析），显示「暂无分镜数据」占位，可手动添加分镜

### 2. 标签编辑与持久化

新增以下函数到 `video-tags.ts`，运行时修改分镜数据：
- `updateShotTag(videoFile, shotId, patch)` — 更新指定分镜的指定字段
- `addShotTag(videoFile, newShot)` — 添加新分镜
- `deleteShotTag(videoFile, shotId)` — 删除指定分镜
- `addCustomTag(videoFile, shotId, tag)` — 给指定分镜添加自定义标签（追加到 tag 字段）

在 `materials.ts` 中新增：
- `updateMaterialShots(materialId, shots)` — 更新素材的分镜缩略图/数量

### 3. 可操作按钮清单

**视频控制**：
- 播放/暂停按钮（视频自带 + 中央大按钮）
- 进度条拖拽
- 全屏按钮

**分镜操作**：
- 上一个/下一个分镜箭头
- 添加分镜按钮（点击打开 ShotTagDialog）
- 删除当前分镜按钮（带确认）
- 编辑当前分镜按钮（打开 ShotTagDialog 预填充）

**标签操作**：
- 待确认标签列表（AI 自动生成）
- 我的标签（自定义标签）
- + 自定义标签按钮（输入框添加）
- 删除标签按钮

**其他**：
- 分辨率切换（原始/720p/480p，占位实现）
- 高级调整（展开更多操作，占位实现）
- 全部保存按钮（保存所有修改，toast 提示成功）

### 4. 打开入口

- **普通模式（非管理员）**：点击素材卡片直接打开详情 Dialog
- **管理员模式**：点击卡片选择 + 双击或点击「预览」按钮打开详情 Dialog
- Dialog 关闭后返回素材列表，筛选状态保持不变

## 具体步骤

1. **数据层改造**：在 `video-tags.ts` 新增 `updateShotTag`/`addShotTag`/`deleteShotTag` 函数
2. **素材数据桥接**：在 `materials.ts` 新增 `getMaterialVideoData(materialId)` 工具函数，从 video-tags 中找到对应视频的分镜数据
3. **新建详情 Dialog 组件**：`MaterialDetailDialog.tsx`，三栏布局，组装播放器+标签面板+时间轴+工具栏
4. **接入素材网格**：修改 `MaterialGridSection.tsx`，点击卡片改为打开详情 Dialog
5. **编辑功能**：接入 ShotTagDialog 实现分镜的增删改，自定义标签的添加删除
6. **联调验证**：点击素材卡片 → 视频可播 → 分镜同步 → 编辑保存生效

## 影响范围与风险

- 复用 VideoTagViewer 的三个子面板（VideoPlayerPanel/TagInfoPanel/ShotTimeline），减少重复代码
- 管理员模式下卡片点击逻辑需调整（单击选中，双击或单独按钮预览），避免与批量选择冲突
- `video-tags.ts` 的运行时修改函数需确保修改后 `getVideoTagsSnapshot()` 能读到最新数据
- 部分素材可能没有对应分镜数据，需有空状态处理

## 验收标准

1. 点击素材卡片打开全屏/大屏详情 Dialog
2. 视频可正常播放、暂停、拖动进度条
3. 播放时右侧标签面板随时间自动切换到当前分镜的标签
4. 点击底部时间轴上的分镜色块，视频跳转到对应时间
5. 点击「编辑」按钮可修改当前分镜的标签字段，保存后立即生效
6. 可添加自定义标签，添加后出现在「我的标签」区域
7. 可删除分镜，删除后时间轴同步更新
8. 「全部保存」按钮点击后 toast 提示保存成功
9. 关闭 Dialog 后素材列表筛选状态保持不变
10. 无 TS 报错，类型检查通过
