## 目标与成功标准

上传素材页面参考用户提供的参考图做 3 处优化：
1. 上传成功后弹出「温馨提示」对话框（而非 toast），提示素材正在打标签/分镜处理中
2. 每个上传任务卡片下方添加「+ 添加标签」按钮，支持上传过程中手动打标签
3. 关于「妙搭开发态」标识：经排查这是妙搭平台注入的开发环境标识，不在应用代码中，无法通过改代码移除，需告知用户

## 关键实现文件

| 文件 | 改动 |
|------|------|
| `client/src/pages/MaterialUploadPage/MaterialUploadPage.tsx` | 新增：上传成功温馨提示 Dialog、任务卡片「+ 添加标签」按钮与标签输入交互 |

## 实现方案

### 1. 上传成功温馨提示 Dialog

- 新增 `successDialogOpen` 状态和 `successMessage` 状态
- 上传完成（`done` 状态）后弹出 Dialog，内容：
  - 标题：「温馨提示」（带 info 图标）
  - 正文：「素材已上传成功，该素材正在进行打标签（或分镜）处理，请稍等约30-40分钟，处理完成后即可在素材中心查看。」
  - 底部：左侧「不再提醒」Checkbox + 右侧「我知道了」按钮
- 勾选「不再提醒」后，通过 localStorage 记录，后续上传不再弹出

### 2. 任务卡片「+ 添加标签」按钮

- 每个 UploadTask 新增 `customTags: string[]` 字段
- 任务卡片文件名下方添加「+ 添加标签」按钮（虚线边框样式）
- 点击后展开输入区域（或弹出小 Dialog），输入标签后回车添加，支持多个标签
- 已添加的标签以 Badge 形式展示在「+ 添加标签」上方
- 标签数据写入 `UploadTask.customTags`，上传完成后同步到素材的 `categoryTags`

### 3. 妙搭开发态标识

- 经全局代码排查：`client/src/` 下所有组件（Layout、Header、app.tsx、index.css 等）均无「开发态」「妙搭开发」「preview」「水印」等 UI 元素
- 该标识是妙搭平台在预览/开发环境注入的全局标识，不在应用代码范围内，**无法通过修改代码移除**
- 实现时在方案说明中告知用户这一情况

## 具体步骤

1. **扩展 UploadTask 类型**：新增 `customTags: string[]` 字段
2. **新增温馨提示 Dialog**：添加 Dialog 组件、状态管理、localStorage 持久化「不再提醒」逻辑，`processFile` 成功分支中触发弹窗
3. **添加任务标签功能**：任务卡片渲染「+ 添加标签」按钮 + 标签输入交互（内联展开式），标签数据保存到 task.customTags
4. **上传完成同步标签**：`createPendingMaterial` 后调用 `updateMaterialTags` 将 customTags 合并到素材的 `categoryTags`

## 影响范围与风险

- 仅影响上传页面 `MaterialUploadPage.tsx`，素材库等其他页面无影响
- 标签功能为前端 mock，刷新页面后自定义标签会丢失（与现有 mock 数据模式一致）
- 「不再提醒」用 localStorage 持久化，清空浏览器数据后恢复

## 验收标准

1. 上传一个素材，上传成功后弹出「温馨提示」Dialog，内容与参考图一致
2. 勾选「不再提醒」后再次上传，不再弹出提示 Dialog
3. 每个上传任务卡片下方都有「+ 添加标签」按钮，点击可展开输入
4. 输入标签后以 Badge 形式展示，可删除已添加的标签
5. 上传完成后，自定义标签同步到素材的分类标签中（素材库可查看到）
6. 任务列表布局保持整齐，标签区域不撑破卡片高度
