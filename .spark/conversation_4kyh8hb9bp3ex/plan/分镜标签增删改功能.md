## 目标与成功标准

在视频分镜标签查看器中，为当前选中视频的分镜标签增加**新增、编辑、删除**功能。所有操作为前端内存操作（mock 数据阶段），刷新后恢复初始数据。

成功标准：
- 用户可在标签面板看到「编辑」和「删除」按钮，点击编辑弹出表单修改当前分镜
- 用户可在时间轴区域看到「新增分镜」按钮，点击弹出表单填写新分镜
- 编辑/新增表单包含产品型号、时间范围、画面描述、场景、物体、动作、镜头、核心卖点、主题、旁白文案等字段
- 新增分镜自动插入到正确的时间位置，时间轴实时更新
- 删除分镜弹出确认对话框，确认后移除

## 实现方案

### 状态管理

主页面将 `MOCK_VIDEO_TAGS` 克隆为 `useState` 的初始值，所有 CRUD 操作修改此 state：

```typescript
const [videoTags, setVideoTags] = useState<VideoTagData[]>(() =>
  JSON.parse(JSON.stringify(MOCK_VIDEO_TAGS))
);
```

三个回调函数：
- `handleAddShot(time: number, data: Partial<ShotTag>)` → 在当前视频的 shots 数组中按 `startTime` 排序插入新分镜，生成 `shotId = shot_${Date.now()}`
- `handleUpdateShot(shotId: string, data: Partial<ShotTag>)` → 找到对应分镜并合并更新
- `handleDeleteShot(shotId: string)` → 从 shots 数组中移除，弹窗确认

操作后重新计算 `totalDuration` 和 `shotCount`。

### ShotTagDialog 表单

新建 `ShotTagDialog.tsx`，支持两种模式：
- **add 模式**：预填当前播放时间作为 startTime，endTime = startTime + 5s，productModel 预填当前视频的产品型号
- **edit 模式**：预填当前分镜的所有字段

表单字段（使用 shadcn Form + Zod 验证）：
- `productModel`（input，选填，预填当前视频产品型号）
- `startTime`（number，必填，≥0）
- `endTime`（number，必填，> startTime）
- `duration`（自动计算）
- `description`（textarea，选填）
- `theme`（input，选填）
- `scene`（input，选填）
- `objects`（input，选填）
- `action`（input，选填）
- `camera`（input，选填）
- `mainSubject`（input，选填）
- `coreSellingPoint`（input，选填）
- `sellingPoint`（input，选填）
- `marketingScene`（input，选填）
- `videoStage`（input，选填）
- `narrationText`（textarea，选填）

### TagInfoPanel 改造

在标题栏右侧增加操作按钮组：
- 编辑按钮（`Pencil` 图标），点击触发 `onEdit(currentShot)`，打开 Dialog
- 删除按钮（`Trash2` 图标），点击触发 `onDelete(currentShot.shotId)`，弹出确认

### ShotTimeline 改造

在标题栏右侧增加「+ 新增分镜」按钮，点击触发 `onAdd(currentTime)`，以当前播放时间为预填 startTime 打开 Dialog。

## 影响范围与风险

- 所有修改集中在 `VideoTagViewerPage/` 目录下，不影响其他页面
- 数据为前端内存操作，刷新页面后恢复初始 mock 数据
- 新增分镜时 shotId 使用时间戳生成，确保唯一性
- 删除操作为不可逆，需要确认弹窗

## 验收标准

1. 选中视频后，右侧标签面板显示「编辑」和「删除」按钮
2. 点击「编辑」→ 弹出 Dialog，表单预填当前分镜数据（含产品型号）→ 修改字段后保存 → 标签面板实时更新
3. 点击「删除」→ 弹出确认对话框 → 确认后分镜从列表和时间轴中移除
4. 时间轴区域「新增分镜」按钮 → 弹出 Dialog，当前播放时间作为默认 startTime，产品型号预填当前视频的产品型号 → 填写后保存 → 分镜按时间插入正确位置
5. 新增/编辑后时间轴色块数量正确更新
6. 切换视频后，原视频的修改不保留（每次切换重新从 mock 数据初始化）
