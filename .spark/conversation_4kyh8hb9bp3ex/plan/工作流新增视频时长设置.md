## 目标与成功标准
- 用户在工作流页面可以设置目标视频时长（秒）
- AI 生成的脚本长度按设置的时长匹配
- AI 视频混剪按设置的时长输出最终视频
- 默认值 45 秒（与当前固定值一致），用户可调整

## 关键实现文件
- `client/src/pages/ProductionLinePage/sections/WorkflowSection.tsx:612-731` — 产品信息面板，新增时长选择器
- `client/src/pages/ProductionLinePage/sections/WorkflowSection.tsx:224-308` — `generateClipForEmployee` 函数，将 duration 传入脚本生成和混剪
- `client/src/pages/ProductionLinePage/sections/WorkflowSection.tsx:420-489` — `handleClipGenerate` 混剪主流程，传递时长参数

## 实现方案

### 1. 产品信息面板新增时长设置
在「产品描述」textarea 下方、「开始 AI 视频混剪」按钮上方，新增一行"视频时长"设置：
- 标签：目标视频时长
- 控件：数字输入框 + 单位"秒"，旁边放快捷选项（15s / 30s / 45s / 60s / 90s）
- 默认值：45
- 校验：最小值 5，最大值 180
- 样式：与产品描述同一视觉层级，shadcn Input + Button group 快捷选择

### 2. 时长传递到脚本生成
新增 state `targetDuration: number`（默认 45）
- `handleClipGenerate` 中把 targetDuration 传给 `generateClipForEmployee`
- `generateClipForEmployee` 第 1 步脚本生成时，在 prompt 中加入"目标视频时长约 ${targetDuration} 秒，按每秒 3-4 字控制旁白字数"，让 AI 按时长生成合适长度的脚本
- `matchScriptToShots` 匹配分镜时，传入 targetDuration，按比例选择分镜数量（目前固定 4 个，改为 `Math.max(2, Math.round(targetDuration / 10))`）

### 3. 时长传递到混剪
`clipVideo` 调用时，将 `duration: 45` 改为 `duration: targetDuration`，让混剪 API 按目标时长输出视频

### 4. 任务记录保存时长
生成的 workflow run 中新增 `targetDuration` 字段（前端 state 中存即可，原型阶段不接数据库），用于任务卡片展示时长信息

## 具体步骤
1. 在 WorkflowSection 组件中新增 `targetDuration` state，默认 45
2. 在产品信息面板的产品描述下方，新增时长设置区域（数字输入 + 快捷按钮组）
3. 修改 `generateClipForEmployee` 函数签名，增加 `targetDuration` 参数
4. 脚本生成 prompt 中加入时长控制描述
5. `matchScriptToShots` 第二个参数从固定 4 改为根据时长计算
6. `clipVideo` 调用的 `duration` 改为动态传入的 targetDuration
7. `handleClipGenerate` 中传递 targetDuration 给 generateClipForEmployee
8. 生成的任务对象中加入 duration 字段，任务卡片展示"XX秒"标签

## 影响范围与风险
- 仅影响工作流页面（/production 的工作流 Tab），不影响看板视图和其他页面
- `matchScriptToShots` 分镜数量按时长动态计算，短时（15s）可能分镜太少，设最小值 2
- 混剪 API 是否支持任意时长取决于后端，但前端先传过去即可，原型阶段不阻塞
- 不影响素材库、监控、迭代等其他模块

## 验收标准
1. 打开生产流水线 → 切换到「工作流」Tab，产品信息面板中有"目标视频时长"设置
2. 默认显示 45 秒，有 15/30/45/60/90 五个快捷按钮
3. 点击快捷按钮，输入框数值对应变化
4. 手动输入数值，范围 5-180，超出时自动修正
5. 选择销售员 + 输入产品描述 + 设置时长后，点击「开始 AI 视频混剪」
6. 生成的脚本长度与设置时长大致匹配（时长短则脚本短）
7. 生成的任务卡片上显示时长标签（如"45秒"）
8. 看板视图中对应任务也展示时长信息
9. 不设置时长（保持默认 45）时，行为与之前一致
