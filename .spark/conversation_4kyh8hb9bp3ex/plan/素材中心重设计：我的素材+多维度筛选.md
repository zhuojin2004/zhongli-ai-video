## 实现方案

### 1. 修复上传视频不可见问题

**根因**：Kimi API 调用失败 → 走 `catch` 分支 → `status='error'` → 从未调用 `addVideoTagData` / `addProductMaterial` → 素材未入库。

**修复**：上传成功后立即用视频基本信息（文件名、上传时间）创建一条「分析中」状态的素材记录并入库，分析完成后更新素材数据（填充分镜、标签、行业等），分析失败则标记为「分析失败」状态。这样无论成功失败，素材都能在列表中看到。

### 2. 数据模型扩展

`IMaterial` 新增字段：
- `industry: string` — 所属行业
- `clientName: string` — 所属客户（即所属员工）
- `department: string` — 所属部门
- `categoryTags: string[]` — 相关标签（功能性能/应用场景/展示呈现/产品属性）
- `quality: '首发' | '优质' | '低质' | '低效' | '同质化'` — 素材质量
- `analysisStatus: 'analyzing' | 'done' | 'failed'` — 分析状态
- `usageCount: number` — 使用次数
- `consumptionCount: number` — 素材消耗量

`addProductMaterial` 改为：接收分析结果后，从结果中提取 industry/clientName/department/categoryTags/quality 等字段。

新增 `updateMaterialTags(id, partial)` 函数：分析完成后更新素材的标签/状态。

### 3. Kimi 分析 prompt 扩展

在现有分镜分析基础上，增加对视频整体的元数据提取要求：
- `industry`：所属行业（从视频内容判断）
- `clientName`：产品/品牌所属客户
- `department`：所属业务部门
- `categoryTags`：分类标签（功能性能/应用场景/展示呈现/产品属性 四类下的具体标签）
- `quality`：素材质量评级

JSON Schema 同步扩展。

### 4. 素材中心页面重设计

**布局**：左侧筛选面板（240px 固定宽）+ 右侧主内容区

**左侧筛选面板**（从上到下）：
- 所属部门：下拉选择（默认项目 / 子公司 A / 子公司 B）
- 所属行业：Chip 选择（全部/汽车行业/物流行业/仓储行业...）
- 所属客户：Chip 选择（全部 + 客户名标签，显示数量）
- 筛选时间：全部/近1天/近7天 + 日期范围
- 相关标签：可折叠，分 4 组（功能性能、应用场景、展示呈现、产品属性），每组展开后多选
- 素材质量：Chip 选择（全部/首发/优质/低质/低效/同质化）

**右侧主内容区**：
- 顶部：素材中心标题 + 副标题
- 工具栏：搜索框（左侧）、排序下拉（素材使用次数/素材消耗量）、操作按钮（素材拷贝/批量添加标签/批量删除，右侧）
- 统计条：当前分镜视频个数 N 个
- 素材网格：3~4 列卡片，缩略图更大，hover 显示操作按钮
- 卡片展示：缩略图 + 视频时长角标 + 产品名 + 标签组（最多 3 个）+ 使用/消耗数据 + 质量角标

### 5. 上传页降级路径

上传成功后立即创建素材（analysisStatus='analyzing'），分析完成后更新素材信息，分析失败则更新为 analysisStatus='failed'，素材仍在列表中可见。

## 具体步骤

1. **扩展数据模型**：修改 `IMaterial` 接口，新增行业/客户/部门/分类标签/质量/分析状态等字段；新增 `updateMaterialTags` 函数
2. **扩展 Kimi 分析**：修改 `shared/api.interface.ts` 的 `AnalyzeVideoResponse` 类型，扩展 JSON Schema 和 prompt
3. **修复上传入库逻辑**：上传成功立即创建素材记录，分析完成后更新，失败标记失败状态
4. **重写素材库页面**：左侧筛选面板 + 右侧网格 + 工具栏 + 统计条
5. **验证**：上传一个视频 → 确认素材列表有「分析中」状态 → 分析完成后标签和行业等字段更新
