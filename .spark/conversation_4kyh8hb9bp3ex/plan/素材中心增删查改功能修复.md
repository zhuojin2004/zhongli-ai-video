## 实现方案

### 1. 数据层：补充 CRUD 四个函数

在 `materials.ts` 中新增：
- `deleteMaterial(id: string): void` — 从 `runtimeMaterials` 中移除指定项
- `deleteMaterials(ids: string[]): void` — 批量移除
- `copyMaterial(id: string): IMaterial` — 深拷贝指定素材，生成新 id，插入 `runtimeMaterials` 头部，返回新素材
- `batchAddTags(ids: string[], tags: string[]): void` — 对指定素材的 `categoryTags` 追加标签（去重）

### 2. 页面层：按钮绑定

在 `MaterialLibraryPage.tsx` 中：
- 「批量删除」按钮：`onClick` 调用 `deleteMaterials(Array.from(selectedIds))`，弹 toast 提示，清空选中
- 「素材拷贝」按钮：遍历 `selectedIds` 调用 `copyMaterial`，弹 toast
- 「批量添加标签」按钮：`onClick` 弹出 Dialog，输入标签（逗号分隔），确认后调用 `batchAddTags`
- 操作后需强制刷新：用 `useState` 计数器触发 `getMaterialsSnapshot()` 重新读取

### 3. 详情弹窗：编辑素材元信息

在 `MaterialDetailDialog.tsx` 中：
- 标题栏右侧新增「编辑素材」按钮（Pencil 图标）
- 点击后弹出内嵌编辑表单（Dialog 内 Dialog），含字段：产品名称、行业、客户、部门、分类标签、质量等级
- 表单用 shadcn Form + Input + Select 组件
- 确认后调用 `updateMaterialTags` 更新素材，并刷新本地数据后用 `toast` 提示

## 具体步骤

1. **`materials.ts` 新增四个函数**：在 `updateMaterialTags` 之后添加 `deleteMaterial`、`deleteMaterials`、`copyMaterial`、`batchAddTags`
2. **`MaterialLibraryPage.tsx` 按钮绑定**：导入新函数，添加 `refreshKey` 状态用于强制刷新，为三个按钮绑定 onClick，新增批量标签 Dialog
3. **`MaterialDetailDialog.tsx` 编辑功能**：在标题区添加编辑按钮，添加编辑表单 Dialog（含 productName/industry/clientName/department/categoryTags/quality 字段），调用 `updateMaterialTags`

## 影响范围与风险

- 素材库为纯内存 mock 数据，刷新页面后增删改操作会丢失，这是已知限制（非本次修复范围）
- 编辑表单需加载 `forms-skill` 获取 shadcn Form 最佳实践
- 详情弹窗内嵌编辑表单要注意 Dialog 嵌套的 z-index 问题，使用独立 Dialog 而非嵌套

## 验收标准

1. 素材中心页选中素材 → 点击「批量删除」→ 素材从网格消失，toast 提示成功
2. 选中素材 → 点击「素材拷贝」→ 网格新增一份拷贝素材（名称带"副本"后缀）
3. 选中素材 → 点击「批量添加标签」→ 弹出对话框输入标签 → 确认后素材标签更新
4. 点击素材卡片 → 详情弹窗 → 点击「编辑素材」→ 修改字段 → 保存后素材信息更新
5. 搜索/筛选/排序/上传功能不受影响，保持原有行为
