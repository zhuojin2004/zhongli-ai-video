## 目标与成功标准

1. 分镜标签查看器页面选择视频后能正常播放，不再黑屏
2. 视频播放时右侧标签面板实时同步当前分镜信息，底部时间轴高亮分镜与视频进度一致

## 根因分析

**视频黑屏**：数据库中 `video_analyses.video_url` 存储的是 dataloom 上传返回的 `download_url`（相对路径格式如 `/spark/app/.../storage/object/...`）。这个路径依赖平台运行时代理来解析，在开发环境下 Vite dev server 可能无法正确代理 `/spark/` 前缀的请求，导致 `<video>` 标签加载失败。

**标签不匹配**：视频黑屏导致 `timeupdate` 事件无法正常触发，`currentTime` 始终为 0，分镜标签固定显示第一个分镜（或空），无法随播放进度同步更新。

## 关键实现文件

- `client/src/pages/VideoTagViewerPage/VideoTagViewerPage.tsx:322` — 将 `videoUrl` 传入 `VideoPlayerPanel` 前，用 dataloom SDK 的 `generateDownloadUrlFromFilePath` 转换为可播放 URL
- `client/src/pages/VideoTagViewerPage/sections/VideoPlayerPanel.tsx:44` — 视频播放器接收转换后的 URL
- `server/modules/video-analysis/video-analysis.service.ts:90-91` — 上传分析时同步存储 `file_path` 字段（可选，如前端方案可行则不需要）
- `server/database/schema.ts` — 如需存储 `file_path`，在 `video_analyses` 表新增字段

## 实现方案

### 方案选择：前端转换（推荐，改动最小）

在 `VideoTagViewerPage` 中，获取视频数据后，用 dataloom SDK 的 `generateDownloadUrlFromFilePath` 将 `videoUrl` 路径转换为可播放的完整 URL。

**关键问题**：`generateDownloadUrlFromFilePath` 需要 `file_path`（dataloom 存储路径），而当前数据库存的是 `download_url`。`download_url` 的格式是 `/spark/app/.../storage/object/bucket_xxx/filename.mp4`，而 `file_path` 格式类似。可以直接将 `download_url` 中 storage 路径后面的部分提取出来作为 `file_path` 传入。

更稳健的做法：上传时同时存储 `file_path`。但考虑改动成本，先尝试前端直接用 `download_url` 路径调用 `generateDownloadUrlFromFilePath`。

### 具体步骤

1. **修改 VideoTagViewerPage.tsx**：在 `getAnalysis` 返回数据后，判断 `videoUrl` 是否为相对路径（以 `/spark/` 开头），若是则调用 dataloom SDK 的 `generateDownloadUrlFromFilePath` 转换为完整 URL（路径格式为 storage 对象路径，如 `/spark/app/app_xxx/runtime/api/v1/storage/object/bucket_xxx/filename.mp4`）。

2. **验证视频播放**：转换后传给 `VideoPlayerPanel`，确认视频能正常播放。

3. **验证标签同步**：视频播放后，`timeupdate` 事件正常触发，`currentTime` 更新，`findCurrentShotIndex` 正确匹配当前分镜，右侧标签面板实时更新。

## 影响范围与风险

- 仅影响 `VideoTagViewerPage` 的视频播放逻辑，不影响其他页面
- 如果 `generateDownloadUrlFromFilePath` 对 `download_url` 格式的路径不兼容，需要 fallback 到原始 `videoUrl` 或在上传时同步存储 `file_path`
- `VideoPlayerPanel` 组件无需修改

## 验收标准

1. 打开分镜标签查看器，选择任意视频，视频能正常播放（非黑屏）
2. 播放视频时，右侧标签面板显示的标签与当前播放时间对应，拖动进度条后标签同步切换
3. 底部时间轴当前分镜色块高亮，已播放分镜半透明，点击色块可跳转
4. 不同的视频切换后，标签数据正确更新
