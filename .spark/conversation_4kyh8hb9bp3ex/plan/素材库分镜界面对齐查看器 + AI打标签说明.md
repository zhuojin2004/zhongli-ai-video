## 目标与成功标准
- 素材库弹窗中的分镜界面与「视频分镜标签查看器」页面的视觉表现一致（左侧大视频 + 右侧标签面板 + 底部时间轴）
- 让用户清楚：上传视频后是有真实 AI 打标签 API 的，上传过程中"AI 分析"步骤就是在调用 `/api/video/analyze` 生成分镜标签

## 关键实现文件
- `client/src/pages/MaterialLibraryPage/sections/MaterialDetailDialog.tsx:277-380` — 素材详情弹窗内容区布局
- `client/src/pages/VideoTagViewerPage/VideoTagViewerPage.tsx:234-264` — 查看器页面布局（参考目标）

## 实现方案

### 素材库弹窗分镜界面对齐查看器
当前弹窗内容区整体是 `flex-1 overflow-y-auto` 滚动容器，视频+标签 grid、时间轴、自定义标签、快捷操作按钮都在里面滚动，导致标签面板和视频高度不一致、视觉割裂。

改成：
1. 把内容区从「整体滚动」改为「上下分区」：上部分是视频 + 标签的 grid（与查看器完全一致），下部分是时间轴 + 自定义标签 + 快捷操作（可滚动）
2. TagInfoPanel 高度与视频区域对齐，不再受 `max-h-[calc(85vh-280px)]` 限制，改为 `overflow-y-auto` 自己滚动
3. 把"自定义标签"和"快捷操作"区域移到时间轴下方，保持视觉层次
4. 整体视觉风格与查看器一致：分镜标签标题区的图标、文字大小、间距对齐
5. 删除弹窗中冗余的"当前素材尚未关联分镜数据"提示的重复显示（已有 videoData 判断）

### AI 打标签说明（不新增代码，在方案中澄清）
- 上传页面第 4 步「AI 分析」就是在调用 AI 打标签 API（`/api/video/analyze`）
- 上传完成后分镜标签数据就已经生成并存入了，素材库弹窗和分镜标签查看器看到的就是 AI 打出来的标签结果
- 上传过程中的步骤文案已经体现了这个流程（上传 → AI分析 → 打标签 → 落库），无需额外改动

## 具体步骤
1. 重构 `MaterialDetailDialog.tsx` 内容区布局：
   - 外层改为 flex 垂直布局，不整体滚动
   - 上半部分：grid `grid-cols-1 lg:grid-cols-3 gap-4`，视频占 2/3，标签占 1/3，高度一致
   - 下半部分：时间轴 + 自定义标签 + 快捷操作，`overflow-y-auto`
2. TagInfoPanel 容器改 `h-full overflow-y-auto`，与视频等高
3. 对齐标题样式：「分镜标签」标题加图标、文字大小统一
4. 保持所有原有功能（编辑/删除分镜、自定义标签、新增分镜、编辑素材元信息）不变

## 影响范围与风险
- 仅影响素材库详情弹窗的视觉布局，不改变任何数据逻辑
- 小屏幕（<1024px）下 grid 堆叠为单列，滚动在底部，保持可用
- 不影响上传流程、AI 分析、分镜查看器页面
