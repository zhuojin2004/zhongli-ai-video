## 实现方案

### 1. 移除重复的"上传素材"按钮

`MaterialLibraryPage.tsx:471-476` 的 `<Link to="/upload">` 包裹的"上传素材"按钮与弹窗上传功能完全重复，直接删除。

### 2. 上传完成后留在素材库

`MaterialLibraryPage.tsx:253-255` 的 `onDrop` 回调中，上传成功后调用了 `fetchMaterials()` 刷新列表，但随后立即 `navigate('/video-tags')` 跳走。删除 `navigate('/video-tags')` 这一行，让用户上传完成后留在素材库看到刷新后的列表。

### 3. 移除 /upload 路由

`app.tsx` 中删除 MaterialUploadPage 的 import（第 7 行）和 `<Route path="upload" ...>`（第 26 行）。MaterialUploadPage 目录文件保留不动，避免删除文件引发其他引用报错。

### 4. 排查 20 个视频未显示的问题

上传链路已验证：`dataloom.storage.uploadFile` → `POST /api/video/analyze` → 后端写入 `video_analyses` 表 → 素材库 `GET /api/materials` 查询 `video_analyses`。链路本身没有问题。实现完成后通过 API 测试工具验证上传接口正常工作，并检查数据库中是否有数据。

## 验收标准

1. 素材库页面工具栏只显示一个"上传视频"按钮，点击弹出上传对话框
