## 目标与成功标准

用户选择目标视频时长（15s/30s/45s/60s/90s）后，生成的脚本字数和分镜总时长严格对齐目标时长，最终合成的视频时长与目标时长偏差 ≤ 10%。

## 关键实现文件

- `client/src/pages/ClipWorkbenchPage/ClipWorkbenchPage.tsx` — 生成流程控制、脚本字数校验、时长估算
- `client/src/pages/ClipWorkbenchPage/RequirementInput.tsx` — 时长选择（已有）
- `server/modules/video-editing/video-editing.service.ts` — `matchShots` 加时长约束算法
- `shared/api.interface.ts` — `MatchShotsRequest` 增加 duration、segmentDurations 字段

## 实现方案

### 1. 脚本生成：明确时长约束 + 字数校验

**问题**：当前 duration 只作为文本拼到 prompt 里，插件不保证输出严格对应时长。

**修复**：
- 脚本生成 prompt 中增加强约束：`"请严格控制脚本朗读时长为 {duration} 秒左右，语速按每秒 3-4 个汉字计算，总字数约 {wordCount} 字。分 {segmentCount} 段，每段约 {segmentWords} 字。"`
- 前端生成脚本后，计算总字数 → 估算朗读时长（每秒 3.5 字）→ 展示「脚本时长预估：X 秒」标签
- 偏差 > 20% 时，显示黄色警告提示「脚本时长与目标偏差较大，建议调整或重新生成」

### 2. 分镜匹配：按目标时长智能选择分镜

**问题**：当前完全不考虑分镜时长，15s 和 60s 返回相同候选。

**修复**：
- `MatchShotsRequest` 增加 `duration: number`（总目标时长）和 `segmentCount: number`（段数）
- `matchShots` 算法升级：
  - 计算每段期望时长 = duration / segmentCount
  - 对每段脚本，先做关键词模糊匹配获取候选池
  - 按「匹配分 - 时长偏离惩罚」排序：`score = keywordHitCount - Math.abs(shotDuration - expectedDuration) / expectedDuration * 0.5`
  - 每段返回 top 3，但总时长累加接近目标
- 返回响应中增加每段的 `estimatedDuration` 字段

### 3. 总时长兜底：自动调整最后一段

- 匹配完所有段后，计算总预估时长
- 若与目标偏差 > 10%，自动调整最后一段的候选分镜（选时长更长/更短的），使总时长尽量接近目标
- 在分镜匹配 Tab 顶部显示「分镜总时长预估：X 秒」进度条

### 4. UI 展示增强

- RequirementInput 下方显示字数参考提示：「15s ≈ 50 字 | 30s ≈ 100 字 | 60s ≈ 200 字」
- 脚本 Tab：每段脚本旁标注预估朗读时长
- 分镜匹配 Tab：每段分镜卡片显示实际时长，汇总显示总时长

## 具体步骤

1. 更新 `shared/api.interface.ts`：`MatchShotsRequest` 加 `duration` 和 `segmentCount` 字段，`ShotCandidate` 加 `shotDuration` 字段
2. 修改 `video-editing.service.ts` 的 `matchShots`：加入时长偏离惩罚排序 + 每段期望时长计算
3. 修改 `ClipWorkbenchPage.tsx`：
   - 脚本生成 prompt 增加严格时长约束和字数要求
   - 脚本生成后计算字数和预估时长，显示标签和偏差警告
   - 调 match-shots 时传入 duration 和 segmentCount
   - 分镜匹配 Tab 显示每段时长和总时长预估
4. 修改 `RequirementInput.tsx`：增加字数参考提示文字

## 影响范围与风险

- 只影响 AI 混剪工作台，不影响素材库、生产流水线等其他模块
- 分镜匹配算法改动后，短时长需求返回的候选分镜可能减少（因为排除了过长的分镜），极端情况下可能候选不足 → 兜底：候选不足时放宽时长约束
- 语速估算（3.5字/秒）是通用值，不同主播语速有差异 → 后续可支持语速调节

## 验收标准

1. 选择 15s 时长生成脚本，脚本字数在 45-60 字范围内（±20% 内）
2. 分镜匹配 Tab 显示每段分镜时长和总时长预估，总时长与目标偏差 ≤ 10%
3. 脚本 Tab 显示「脚本时长预估：X 秒」标签，偏差 >20% 有警告
4. 所有接口调用正常，无类型错误
5. 短时长需求（如 15s）不会匹配到总时长远超目标的分镜组合
