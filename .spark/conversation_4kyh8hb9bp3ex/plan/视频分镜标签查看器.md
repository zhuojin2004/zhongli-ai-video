## 目标与成功标准

在现有系统中新增一个独立页面「视频分镜标签查看器」，让员工可以：
- 从下拉菜单选择要查看的视频
- 左侧播放视频，右侧实时展示当前播放时间对应的分镜标签
- 底部时间轴展示所有分镜分布，点击可跳转到对应时间点
- 视频播放过程中，标签面板自动同步切换

## 关键实现文件

| 文件 | 操作 | 说明 |
|------|------|------|

| `client/src/pages/VideoTagViewerPage/VideoTagViewerPage.tsx` | 新建 | 页面主组件，管理视频选择和播放状态 |

| `client/src/pages/VideoTagViewerPage/sections/ShotTimeline.tsx` | 新建 | 底部分镜时间轴，可视化所有分镜的时间分布 |

## 实现方案

### 数据层

Mock 数据从 Excel 读取后写入 `client/src/data/video-tags.ts`，结构为：

```typescript
interface ShotTag {
  shotId: string;
  videoFile: string;
  startTime: number;
  endTime: number;
  description: string;
  productModel: string;
  theme: string;
  scene: string;
  objects: string;
  action: string;
  camera: string;
  mainSubject: string;
  coreSellingPoint: string;
}
interface VideoTagData {
  videoFile: string;
  videoUrl: string;
  productModel: string;
  shots: ShotTag[];
}
```

- videoUrl 使用现有 production_tasks 中对应产品的 videoUrl 或占位符
- 用 Python 脚本将 Excel 数据转换为 TypeScript 对象数组写入 mock 文件

### 页面布局

```
┌──────────────────────────────────────────────┐
│  [视频选择器: 下拉菜单选视频]                  │
├──────────────────────┬───────────────────────┤
│                      │  当前分镜标签          │
│                      │  ┌─────────────────┐  │
│   视频播放器          │  │ 时间范围         │  │
│   (aspect-video)     │  │ 画面描述         │  │
│                      │  │ 场景 / 物体      │  │
│                      │  │ 动作 / 镜头      │  │
│                      │  │ 核心卖点         │  │
│                      │  │ 主题             │  │
│                      │  └─────────────────┘  │
│                      │                       │
│                      │  关键帧预览图          │
├──────────────────────┴───────────────────────┤
│  分镜时间轴 (每个分镜一个色块，当前高亮)       │
└──────────────────────────────────────────────┘
```

### 核心交互逻辑

1. **视频选择**：顶部下拉菜单列出所有 mock 视频，选中后加载对应分镜数据并重置播放器
2. **播放同步**：监听 `<video>` 的 `timeupdate` 事件，根据 `currentTime` 查找当前命中的分镜（`startTime <= currentTime < endTime`），更新标签面板
3. **时间轴跳转**：点击时间轴上的分镜色块，视频跳转到对应 `startTime`
4. **当前分镜高亮**：时间轴中当前分镜色块以 primary 色高亮，已播放分镜为半透明

### 视觉风格

- 遵循项目深色控制台风格（`bg-background` / `bg-card`）
- 标签面板使用卡片式布局，标签字段以 key-value 形式展示
- 时间轴使用水平条形图，每个分镜宽度正比于时长
- 当前分镜标签面板有微光脉冲动效提示

## 具体步骤

1. **生成 mock 数据**：用 Python 脚本读取 Excel，将 508 条分镜数据转换为 TypeScript 格式，写入 `client/src/data/video-tags.ts`，按视频文件分组
2. **创建页面文件结构**：新建 `client/src/pages/VideoTagViewerPage/` 目录及 `VideoTagViewerPage.tsx`、`sections/` 子目录
3. **实现 VideoPlayerPanel**：左侧视频播放器组件，使用原生 `<video>` 标签，通过 `useRef` 获取视频元素，向上暴露 `onTimeUpdate` 回调
4. **实现 TagInfoPanel**：右侧标签展示面板，接收当前分镜数据，展示画面描述、场景、物体、动作、镜头、核心卖点等字段
5. **实现 ShotTimeline**：底部分镜时间轴，根据所有分镜的 startTime/endTime 绘制色块，支持点击跳转
6. **实现 VideoTagViewerPage 主组件**：组合上述三个组件，管理视频选择状态、当前播放时间、当前分镜查找逻辑
7. **注册路由和导航**：在 `app.tsx` 添加路由，在 `AppSidebar.tsx` 添加导航项（图标使用 `Tags` 或 `Clapperboard`）

## 影响范围与风险

- **新增功能，不影响现有页面**：所有文件为新建，仅 AppSidebar 和 app.tsx 有新增行
- **视频 URL 为占位符**：mock 数据中 videoUrl 暂时为空或占位 URL，后续可对接真实视频
- **关键帧图片路径**：Excel 中 keyframePath 为 `/tmp/video_shots/...`，这是服务端临时路径，前端无法直接访问。时间轴中不展示关键帧缩略图，仅展示色块

## 验收标准

1. 页面从导航栏「分镜标签」可进入，路由 `/video-tags` 正常
2. 顶部下拉菜单列出所有 20 个视频，默认选中第一个
3. 选中视频后，左侧视频播放器加载（videoUrl 有值时正常播放）
4. 右侧标签面板展示当前播放时间对应的分镜信息，字段包括：时间范围、画面描述、场景、物体、动作、镜头、核心卖点、主题
5. 底部分镜时间轴展示所有分镜色块，当前分镜高亮
6. 拖拽视频进度条 / 点击时间轴色块，标签面板同步更新
7. 页面风格与现有深色控制台风格一致
