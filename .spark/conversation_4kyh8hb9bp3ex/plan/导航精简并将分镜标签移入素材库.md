# 导航精简 + 素材库内查看分镜标签

## 1. 目标与成功标准

- 左侧导航精简为 **4 项**：素材库、AI 混剪、生产流水线、内容迭代中心
- 「素材上传」从导航移除——素材库页面已有上传入口（顶部"上传视频"按钮 + Dialog）
- 「分镜标签」从导航移除——在素材库内点击视频卡片即可查看该视频的分镜标签
- `/video-tags` 路由保留（直接访问 URL 仍可进入），仅从导航隐藏

## 2. 关键实现文件

| 文件 | 改动 |
|---|---|
| `client/src/components/AppSidebar.tsx` | 从三套角色导航（operator/user/admin）中移除「素材上传」和「分镜标签」两项 |
| `client/src/pages/MaterialLibraryPage/sections/MaterialGridSection.tsx` | 详情弹窗中补充分镜标签展示区域 |
| `client/src/pages/MaterialLibraryPage/MaterialLibraryPage.tsx` | 传入 shots 数据或提供按 analysisId 查 shots 的方法 |
| `client/src/api/video-analysis.ts` 或 `client/src/api/materials.ts` | 确认/新增按 analysisId 获取分镜列表的 API 调用 |

## 3. 现有事实（已验证）

- 导航配置在 `AppSidebar.tsx:31-52`，三套角色（operator/user/admin），每套都含「素材上传」和「分镜标签」
- 「素材上传」页 `MaterialUploadPage.tsx` **文件存在但未注册路由**，侧栏点击会落到 NotFoundPage（本来就是坏的）
- 素材库页面顶部已有"上传视频"按钮（`MaterialLibraryPage.tsx:469-471`），打开 Dialog 走 `uploadOpen` 状态
- 素材库点视频卡片 → 打开 `MaterialDetailDialog`（Dialog 弹窗），由 `MaterialGridSection.tsx` 的 `selected` 状态控制
- 「分镜标签」页路由为 `/video-tags`（`app.tsx:31`），三套角色导航均含此项

## 4. 实现方案

### 4.1 导航精简
- 从 `ROLE_NAV_ITEMS` 的三套配置中同时移除：
  - 素材上传（path: `/upload`，icon: Upload）
  - 分镜标签（path: `/video-tags`，icon: Tags / 对应图标）
- 剩余 4 项保持原顺序：素材库 → AI 混剪 → 生产流水线 → 内容迭代中心
- `app.tsx` 中的 `/video-tags` 路由保留，不删除（URL 直达仍可用）

### 4.2 素材库详情弹窗补充分镜标签
- 先读取 `MaterialDetailDialog` 当前内容，确认已有字段
- 在弹窗中新增「分镜标签」区块，展示该视频的所有分镜：
  - 分镜序号、时间区间（`startTime - endTime`，格式化为 mm:ss）
  - 画面描述（description）
  - 场景（scene）、动作（action）、核心卖点（coreSellingPoint）
  - 旁白文案（narrationText）
- 数据获取：调用现有接口（`/api/video/shots` 或 `/api/materials/:id/shots`），按 `analysisId` 过滤
  - 若已有按 analysisId 查 shots 的能力 → 直接复用
  - 若只有全量 shots 接口 → 前端按 analysisId 过滤
- 分镜过多时内部滚动，弹窗高度限制为 `max-h-[70vh]`

### 4.3 不动的部分
- 不删除 `MaterialUploadPage.tsx` 文件（保留但不引用）
- 不删除 `/video-tags` 路由（保留直接访问能力）
- 不改动素材库上传 Dialog 的现有逻辑
- 不改动 VideoTagViewerPage 本身

## 5. 具体步骤

1. 读 `AppSidebar.tsx` 完整导航配置，确认三套角色各含哪些项、图标是什么
2. 编辑 `AppSidebar.tsx`，同时从三套角色配置中移除「素材上传」和「分镜标签」
3. 读 `MaterialDetailDialog`（或 `MaterialGridSection.tsx` 中的详情部分），确认当前展示字段
4. 读现有 `/api/video/shots` 接口（controller + service），确认是否支持按 analysisId 查询
5. 在详情弹窗中补充分镜标签列表区域，传入正确的 analysisId 获取数据
6. 手动验证：素材库点视频卡片 → 弹窗中看到分镜标签

## 6. 影响范围与风险

- **导航可见性**：三套角色同步精简，体验一致；不影响路由
- **详情弹窗高度**：新增分镜标签区块后弹窗变高，需加 `max-h-[70vh] overflow-y-auto` 防溢出
- **数据加载**：详情弹窗打开时才加载分镜数据（懒加载），避免列表页变慢
- **向后兼容**：`/video-tags` 路由保留，书签/外链不受影响
