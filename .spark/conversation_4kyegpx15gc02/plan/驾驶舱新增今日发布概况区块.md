## 目标与成功标准

在总览驾驶舱新增「今日发布概况」区块，展示今天有多少业务员和经销商发布了视频，以及各自占其总人数的比例。

## 关键实现文件

- `src/data/dashboard.ts` — 新增 `IDailyPublishStats` 接口和 mock 数据
- `src/pages/DashboardPage/sections/TodayPublishSection.tsx` — **新建**，今日发布概况组件
- `src/pages/DashboardPage/DashboardPage.tsx` — import 新 Section 并插入布局

## 实现方案

### 数据模型

在 `src/data/dashboard.ts` 新增接口和 mock：

```ts
export interface IDailyPublishStats {
  totalInternal: number   // 业务员总数
  todayInternal: number   // 今日已发布业务员数
  totalDealer: number     // 经销商总数
  todayDealer: number     // 今日已发布经销商数
}
```

Mock 数据：业务员 200 人，今日已发 142 人；经销商 1000 家，今日已发 386 家。

在 `IDashboardData` 中新增字段 `dailyPublish: IDailyPublishStats`，在 `MOCK_DASHBOARD` 中补充该字段。

### 组件设计

`TodayPublishSection` 接收 `IDailyPublishStats` props，展示两张并排卡片：

- 左侧「业务员」卡片：显示 `todayInternal / totalInternal` 和百分比进度条
- 右侧「经销商」卡片：显示 `todayDealer / totalDealer` 和百分比进度条

每张卡片包含：标题 + 已发布数/总数 + 百分比进度条（带渐变色）+ 百分比数字

### 布局位置

在 KPI 卡片行下方、销售趋势图上方插入，作为独立区块。

## 具体步骤

1. **修改 `src/data/dashboard.ts`**：新增 `IDailyPublishStats` 接口，在 `IDashboardData` 中加 `dailyPublish` 字段，在 `MOCK_DASHBOARD` 中加 mock 数据
2. **新建 `TodayPublishSection.tsx`**：两张并排卡片，展示业务员和经销商的今日发布比例，含进度条
3. **修改 `DashboardPage.tsx`**：import 新 Section，在 KpiCardsSection 和图表区之间插入

## 影响范围与风险

- 仅影响 Dashboard 页面，不影响其他 5 个模块
- 数据为纯 mock，不涉及真实数据源
- KPI 卡片行布局不变，新 Section 为独立区块

## 验收标准

1. 总览驾驶舱出现「今日发布概况」区块
2. 左侧卡片显示业务员今日发布数/总数及百分比
3. 右侧卡片显示经销商今日发布数/总数及百分比
4. 进度条颜色与百分比数值对应（高比例偏绿，低比例偏黄）
5. 百分比 = 已发布数 ÷ 总数 × 100%，保留 1 位小数
