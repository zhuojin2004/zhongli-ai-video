## 目标与成功标准

将竞品监控的搜索范围从「全网搜索」收窄为「视频号定向搜索」，确保抓取到的数据聚焦于「中力老潘」「老何说叉车」在微信视频号上的视频内容与流量表现。

## 关键实现文件

- `src/pages/DashboardPage/sections/CompetitorMonitorSection.tsx` — 更新搜索 query，将搜索限定在视频号平台

## 实现方案

### 搜索 query 改为视频号定向

将 `COMPETITORS` 数组中的 query 从通用搜索改为视频号平台限定：

```
中力老潘 → "中力老潘 视频号 最新视频 播放量 点赞 评论 内容分析"
老何说叉车 → "老何说叉车 视频号 最新视频 播放量 点赞 评论 内容分析"
```

同时调整 `additional_search_requirements` 参数，明确要求 AI 搜索摘要聚焦于视频号平台的数据，包括视频标题、发布时间、播放量、点赞数、评论数、转发数等具体指标。

### 展示优化

竞品分析结果中，对视频数据类指标（播放量/点赞/评论/转发）做加粗强调，方便管理层快速对比竞品视频表现。

## 具体步骤

1. **修改 CompetitorMonitorSection.tsx**：更新 `COMPETITORS` 的 query 和 `fetchCompetitor` 中的 `additional_search_requirements`，限定平台为视频号，要求输出视频维度的具体数据

## 影响范围与风险

- 仅修改搜索参数，不改变插件调用逻辑和 UI 结构
- 搜索结果质量取决于搜索引擎对视频号内容的收录程度，可能存在数据不全的情况

## 验收标准

1. 点击「分析中力老潘」后，搜索摘要聚焦于该博主的视频号内容
2. 分析结果包含视频标题、发布时间、播放量、点赞数等视频维度数据
3. 点击「分析老何说叉车」同理
4. 页面刷新后重新分析，数据基于最新搜索结果
