## 目标与成功标准

删掉驾驶舱中两个销售相关模块（KPI 指标卡片行 + 销售趋势图），替换为视频平台数据模块，让驾驶舱聚焦于视频内容生产与发布的数据监控。

## 关键实现文件

- `src/pages/DashboardPage/DashboardPage.tsx` — 删除 KpiCardsSection 和 SalesTrendSection 的导入与渲染，替换为新的视频数据模块
- `src/pages/DashboardPage/sections/KpiCardsSection.tsx` — 保留不动（其他页面可能引用）
- `src/pages/DashboardPage/sections/SalesTrendSection.tsx` — 保留不动（其他页面可能引用）
- `src/pages/DashboardPage/sections/VideoKpiCardsSection.tsx` — **新建**，视频平台 KPI 卡片行（总视频数/总播放量/总点赞/总评论/今日发布/活跃账号）
- `src/pages/DashboardPage/sections/VideoTrendSection.tsx` — **新建**，视频播放量趋势折线图（近 7 天）
- `src/data/dashboard.ts` — 新增 `videoKpis` 和 `videoTrend` mock 数据字段

## 实现方案

### 删除销售模块

从 DashboardPage 中移除：
- `KpiCardsSection` 组件及其 `kpis` prop
- `SalesTrendSection` 组件及其外层 `grid grid-cols-1 lg:grid-cols-3` 布局容器

### 新增视频数据模块

**VideoKpiCardsSection**（6 张卡片，复用原 KPI 卡片布局）：
- 总视频数：所有账号已发布视频总数
- 总播放量：累计播放量
- 总点赞数：累计点赞
- 总评论数：累计评论
- 今日发布：当日新发布视频数
- 活跃账号数：近 7 天有发布行为的账号数

**VideoTrendSection**（全宽折线图，替换原 SalesTrendSection + PipelineOverviewSection 的 2:1 布局）：
- 近 7 天视频播放量趋势折线图
- 可叠加显示点赞数趋势线

### 布局调整

原布局为 `grid-cols-1 lg:grid-cols-3`（SalesTrend 占 2/3 + PipelineOverview 占 1/3），删除后改为：
- VideoKpiCardsSection 全宽
- VideoTrendSection 全宽
- PipelineOverviewSection 保留，单独一行
- TodayPublishSection、RecentContentSection、CompetitorMonitorSection 保持原位置

## 具体步骤

1. **修改 `src/data/dashboard.ts`**：新增 `IVideoKPI`、`IVideoTrendPoint` 接口，在 `IDashboardData` 和 `MOCK_DASHBOARD` 中新增 `videoKpis` 和 `videoTrend` 字段
2. **新建 `VideoKpiCardsSection.tsx`**：6 张视频 KPI 卡片，样式与现有 KpiCardsSection 一致
3. **新建 `VideoTrendSection.tsx`**：近 7 天播放量趋势折线图，使用 recharts 或 echarts
4. **修改 `DashboardPage.tsx`**：删除销售模块导入，导入新组件，调整布局

## 影响范围与风险

- KpiCardsSection 和 SalesTrendSection 文件保留不动，仅 DashboardPage 不再引用
- mock 数据扩展，不影响现有页面
- 视频 KPI 数据为模拟数据，后续可接入真实视频平台 API

## 验收标准

1. 驾驶舱不再显示「总目标/预估完成/缺口/内销/外销/去年同期」6 张销售 KPI 卡片
2. 驾驶舱不再显示「销售趋势（近 7 天）」折线图
3. 驾驶舱出现 6 张视频数据 KPI 卡片（总视频数/总播放量/总点赞/总评论/今日发布/活跃账号）
4. 驾驶舱出现视频播放量趋势折线图
5. PipelineOverviewSection、TodayPublishSection、RecentContentSection、CompetitorMonitorSection 保持正常显示
6. 页面布局整洁，无空白区域
