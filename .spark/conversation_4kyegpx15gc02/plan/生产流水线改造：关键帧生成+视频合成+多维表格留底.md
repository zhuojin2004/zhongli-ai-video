## 目标与成功标准

1. 工作流中「产品图生成」替换为「关键帧生成」，基于脚本内容生成多张关键帧图
2. 新增「视频合成」环节，将关键帧+音频组合为可播放的视频素材
3. 看板任务卡片展示：脚本摘要、关键帧缩略图、视频预览
4. 完成后自动将脚本、关键帧、视频 URL、销售员姓名写入飞书多维表格留底

## 关键实现文件

- `src/data/production.ts` — `IProductionTask` 新增 `keyframes: string[]` 字段
- `src/pages/ProductionLinePage/sections/WorkflowSection.tsx` — 重构流水线：脚本→关键帧(3张)→视频合成→保存多维表格
- `src/pages/ProductionLinePage/sections/PipelineBoardSection.tsx` — 任务卡片+详情弹窗展示关键帧缩略图和视频预览
- 新建 `feishu-bitable` 插件实例 — 用于生产记录落库

## 实现方案

### 1. 数据模型扩展

`IProductionTask` 新增 `keyframes: string[]`（关键帧图片 URL 数组），`videoUrl` 保留用于最终视频。

### 2. 工作流流水线重构（4 阶段）

| 阶段 | 插件 | 说明 |
|------|------|------|
| ① 脚本生成 | `ai-text-generate` (已有) | 不变 |
| ② 关键帧生成 | `ai-text-to-image` (新) | 基于脚本内容生成 3 张 16:9 关键帧 |
| ③ 语音合成 | `ai-speech-synthesis` (已有) | 不变 |
| ④ 视频合成 | 前端组合 | 将关键帧序列+音频组合为可播放素材（因 Seedance 2.0 不在当前插件目录，用关键帧轮播+音频叠加模拟视频效果） |

> 注：Seedance 2.0 等专业视频生成 API 当前不在官方插件目录中，暂用关键帧序列+音频合成的方案替代。后续如有对应插件可无缝替换阶段④。

### 3. 看板卡片增强

- 任务卡片增加关键帧缩略图（首帧小图，hover 预览）
- 详情弹窗展示：脚本全文、关键帧画廊（3 张）、视频播放器

### 4. 多维表格留底

创建 `feishu-bitable` 插件实例，每条生产任务完成后调用 `batchAddRecords` 写入：
- 销售员姓名、产品名称、脚本内容、关键帧 URL（逗号分隔）、视频 URL、生成时间

## 具体步骤

1. **创建 bitable 插件实例**：emit `plugin_instance` 创建 feishu-bitable 实例，用于生产记录表
2. **修改 `src/data/production.ts`**：`IProductionTask` 加 `keyframes: string[]`，mock 数据补齐
3. **重构 `WorkflowSection.tsx`**：
   - 阶段②替换为关键帧生成（调用 `ai-text-to-image`，prompt 基于脚本摘要，生成 3 张）
   - 阶段④改为视频合成（关键帧轮播+音频叠加）
   - 完成后调用 `capabilityClient.load(bitableId).call('batchAddRecords', ...)` 写入多维表格
4. **修改 `PipelineBoardSection.tsx`**：任务卡片增加关键帧缩略图，详情弹窗增加关键帧画廊和视频播放区
5. **调整 `IProductionTask` 引用处**：`ProductionHeaderSection` 创建任务时补齐 `keyframes` 字段

## 影响范围与风险

- `WorkflowSection` 改动较大，需保证流式脚本生成、关键帧生成、语音合成的异步流程稳定
- 关键帧生成 3 张图耗时约 15-45 秒，需有 loading 提示
- bitable 插件实例需要用户确认多维表格结构（字段名需与 `batchAddRecords` 的字段映射一致）
- 视频合成当前为前端模拟（关键帧轮播+音频），非真实 mp4 文件

## 验收标准

1. 选择销售员+输入产品描述 → 点击生成 → 依次展示「脚本生成→关键帧生成→语音合成→视频合成」四阶段，每阶段有 loading 状态
2. 完成后展示 3 张关键帧缩略图 + 可播放的音频 + 关键帧轮播视频
3. 看板「已混剪」列出现新任务卡片，含关键帧首帧缩略图
4. 点击任务卡片 → 详情弹窗展示脚本全文、3 张关键帧、视频播放器
5. 多维表格中新增一条记录，包含销售员、脚本、关键帧 URL、视频 URL

## 未决事项

- **多维表格字段结构**：需确认目标表格的字段名（销售员、脚本、关键帧、视频 URL 等），否则 `batchAddRecords` 的字段映射可能不匹配。建议先创建插件实例后查看实际字段。
