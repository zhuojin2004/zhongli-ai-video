## 目标与成功标准

工作流生成完成后，历史记录中完整保存四个阶段的产物：脚本、关键帧、语音、视频 URL。用户点击「查看详情」能同时看到脚本、关键帧缩略图和音频播放器。

## 关键实现文件

- `client/src/data/production.ts` — `IProductionTask` 接口新增 `audioUrl` 字段
- `client/src/pages/ProductionLinePage/sections/WorkflowSection.tsx` — `generateForEmployee` 返回 `audioUrl`；`handleGenerate` 使用 `task.audioUrl` 替代 `generatedAudioUrl` 状态

## 实现方案

**根因**：`generateForEmployee` 内部拿到 `speechResult.audioUrl` 后只调了 `setGeneratedAudioUrl` 更新 React 状态，没有把它放进返回的 task 对象。`handleGenerate` 中 `createRun` 读的是 React 状态 `generatedAudioUrl`，由于 React 批量更新，函数返回时状态尚未刷新，拿到的是空字符串。

**修复**：
1. `IProductionTask` 接口新增 `audioUrl?: string`
2. `generateForEmployee` 内部用局部变量 `audioUrl` 捕获语音合成结果，写进 return 的 task 对象
3. `handleGenerate` 中 `createRun` 的 `audioUrl` 改用 `task.audioUrl`

## 具体步骤

1. `client/src/data/production.ts`：`IProductionTask` 接口增加 `audioUrl?: string`
2. `client/src/pages/ProductionLinePage/sections/WorkflowSection.tsx`：
   - `generateForEmployee` 中声明 `let audioUrl = ''` 局部变量，语音合成成功后赋值 `audioUrl = speechResult.audioUrl`，return 时带上 `audioUrl`
   - `handleGenerate` 中 `createRun` 调用将 `audioUrl: generatedAudioUrl` 改为 `audioUrl: task.audioUrl || ''`

## 影响范围与风险

- 仅影响 `IProductionTask` 类型和 `WorkflowSection` 组件，不涉及其他页面
- `IProductionTask` 新增字段为可选，不会破坏现有引用
- 历史记录中 `audioUrl` 为空的老记录查看详情时音频播放器不显示，行为正常

## 验收标准

1. 完成一次 AI 生成 → 历史记录中音频 URL 有值
2. 点击「查看详情」→ 弹窗中显示音频播放器
3. 生成失败时不保存历史记录（现有行为不变）
