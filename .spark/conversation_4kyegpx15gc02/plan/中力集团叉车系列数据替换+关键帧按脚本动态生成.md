## 目标与成功标准

1. 双素材库产品卡片、生产流水线 mock 任务全部替换为中力集团叉车系列数据
2. 关键帧数量不再固定 3 张，改为根据脚本段落数动态生成（每段一个关键帧，2-5 张）

## 关键实现文件

- `src/data/materials.ts` — 产品素材 mock 数据替换为 3 款叉车产品
- `src/data/production.ts` — 生产任务 mock 数据替换为叉车相关
- `src/pages/ProductionLinePage/sections/WorkflowSection.tsx` — 关键帧按脚本段落动态生成

## 实现方案

### 1. 产品素材替换

将 3 个汽车产品替换为中力集团叉车系列：

| 旧产品 | 新产品 |
|--------|--------|
| 旗舰SUV-越野套装 | 中力 E-TRUCK 电动平衡重叉车（3.5吨） |
| 家用MPV-舒适版 | 中力 E-STACKER 电动堆高车（2吨） |
| 纯电轿跑-性能版 | 中力 E-PALLET 电动搬运车（1.5吨） |

- 卖点标签对应更新（如"零排放""智能操控""超长续航"等）
- 头像保持不动（员工数据不变）

### 2. 生产任务 mock 替换

3 条任务的产品名、脚本、标签替换为叉车相关内容，assignee 不变。

### 3. 关键帧动态生成

`WorkflowSection.tsx` 中关键帧生成逻辑改为：
- 脚本按空行拆分为段落，取非空段落
- 段落数 clamp 到 2-5 范围
- 每个段落生成一个关键帧 prompt：`{产品描述}，{段落摘要}，16:9 商业摄影`
- 取代原来固定 3 张 hardcoded prompts

## 具体步骤

1. 修改 `materials.ts`：替换 3 个产品对象的 productName、sellingPointTags、thumbnailUrl 占位
2. 修改 `production.ts`：替换 3 条 mock 任务的 productName、script、tags
3. 修改 `WorkflowSection.tsx`：`handleGenerate` 中阶段②改为按段落拆脚本生成 N 个 prompt

## 影响范围与风险

- 素材库页面自动展示新数据，无需额外改动
- 生产流水线看板卡片自动展示新数据
- 关键帧数量变化后，UI 已支持任意数量（缩略图滚动、画廊切换），无需额外改动

## 验收标准

1. 双素材库「产品素材库」Tab 显示 3 款叉车产品卡片
2. 生产流水线看板中 3 条 mock 任务为叉车相关内容
3. 工作流生成脚本后，关键帧数量 = 脚本段落数（2-5 张），不再是固定 3 张
4. 短脚本（1 段）生成 2 张关键帧，长脚本（5+ 段）生成 5 张关键帧
